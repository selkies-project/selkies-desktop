The first release of the Rust desktop, replacing the C program the images built from source.

One static binary per architecture, `selkies-desktop-x86_64` and `selkies-desktop-aarch64`, each with a `.sha256` beside it. The binary links no system library and runs on every distribution the Selkies images are built from; an image installs it by placing the file at `/usr/bin/selkies-desktop`.

What it does, over labwc or openbox:

- Start menu with search, favorites, recent applications and categories from the desktop files, refreshed as applications come and go.
- Taskbar with icons, tooltips, a window menu and wheel cycling; clock with a calendar; volume for the PulseAudio sink; show desktop.
- Wallpaper on every monitor, a solid or gradient background, the Selkies logo by default, and launchers from `~/Desktop`.
- Quick launch buttons and an XEmbed system tray, under labwc through XWayland.
- A file manager: places, icon and list views with thumbnails, sorting, breadcrumbs, cut, copy, paste, rename, new folder, permanent delete behind a confirmation, and drags between windows, to the desktop and to other applications on Wayland.
- A settings window from a right click on the bar: the bar's edge, auto-hide, height, width, opacity, icon, label, layout and margin, the items it shows, quick launch, favorites and the start menu's layout, the file manager's defaults, the wallpaper per monitor, and a Theme page.
- Theming of the whole desktop from the Theme page, with a preview that draws the wallpaper, two windows, the start menu and the bar as they would look. A dark and a light scheme, the four colors of the interface from twelve presets each or a picker with a spectrum and a hex field that shows the color on screen as it is dragged, and three styles: Linux, Fruit with a floating dock, circle buttons on the left, glossy title bars and a grid of applications, and Redmond with square frames, wide buttons and a start menu of every application beside the favorites as tiles. The shading, the side the buttons sit on, their glyphs, the corner radius, the bar's layout and margin and the start menu's layout can each be set alone.
- Window frames that follow the theme. A window manager theme is generated from the colors and the frame settings under `~/.themes`, where labwc and openbox both look before the system themes, and the running window manager reloads it at once, so title bars, borders and the right-click menus match the bar and the popups. The button side and corners are written into the window manager's `rc.xml` where the image leaves it writable, and labwc's rule that forced server-side decorations on every window is relaxed so browsers, Steam and other applications that draw their own frames no longer get a second one. The `theme_windows` key turns the generated theme off and removes it.
- Scrollbars on the file manager, the settings window and every list taller than its area, with a thumb to drag and a track that jumps.
- Nineteen languages, chosen from the locale environment or the `language` setting.
- HiDPI rendering at the output's scale.

Configuration is `~/.config/selkies-desktop/config`, every key also settable as `SELKIES_DESKTOP_<KEY>` in the environment; the README lists the keys.
