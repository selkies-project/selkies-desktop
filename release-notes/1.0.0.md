The first release of the Rust desktop, replacing the C program the images built from source.

One static binary per architecture, `selkies-desktop-x86_64` and `selkies-desktop-aarch64`, each with a `.sha256` beside it. The binary links no system library and runs on every distribution the Selkies images are built from; an image installs it by placing the file at `/usr/bin/selkies-desktop`.

What it does, over labwc or openbox:

- Start menu with search, favorites, recent applications and categories from the desktop files, refreshed as applications come and go.
- Taskbar with icons, tooltips, a window menu and wheel cycling; clock with a calendar; volume for the PulseAudio sink; show desktop.
- Wallpaper on every monitor, a solid or gradient background, the Selkies logo by default, and launchers from `~/Desktop`.
- Quick launch buttons and an XEmbed system tray, under labwc through XWayland.
- A file manager: places, icon and list views with thumbnails, sorting, breadcrumbs, cut, copy, paste, rename, new folder, permanent delete behind a confirmation, and drags between windows, to the desktop and to other applications on Wayland.
- A settings window from a right click on the bar: the bar's edge, auto-hide, height, width, opacity and icon, the items it shows, quick launch and favorites, the file manager's defaults, the wallpaper per monitor, and the four colors of the interface.
- Nineteen languages, chosen from the locale environment or the `language` setting.
- HiDPI rendering at the output's scale.

Configuration is `~/.config/selkies-desktop/config`, every key also settable as `SELKIES_DESKTOP_<KEY>` in the environment; the README lists the keys.
